Project summary

Masters' Union Feed UI

This project recreates a polished social learning feed for Masters' Union. The work focuses on translating a detailed product interface into a responsive, interactive HTML prototype with structured feed cards, navigation, filters, reactions, comments, and branded visual styling.

What Was Built

A product-like feed screen with real interface states and microinteractions.

01

Branded dashboard shell

Created a fixed topbar, left navigation rail, profile area, search control, notification affordance, and a dark Masters' Union styled canvas.

02

Feed content system

03

Interactive behavior

Work Breakdown

The project moves from layout foundation to interaction polish.

Interface foundation

Set up the document structure, typography, theme variables, dark color system, fixed navigation areas, and the main dashboard layout.

Feed composition

Built multiple content card types including file attachment posts, article previews, long text posts, author identity blocks, and engagement controls.

Responsive refinement

Added media queries for desktop, tablet, and mobile widths so the sidebar, toolbar, cards, attachments, and comment controls adapt cleanly.

Preview workflow

Included lightweight local server options through preview-server.js and server.ps1 to serve the prototype and asset files from port 4173.

Key Features

These are the visible and functional pieces delivered in the prototype.

  • Search experience: A rounded search input with keyboard shortcut styling for a modern dashboard feel.
  • Feed tabs: Latest, Trending, and For You filters driven by data attributes and JavaScript state updates.
  • Post actions: Like buttons update the active style and adjust counts without reloading the page.
  • Comment forms: Users can submit text, clear the input, and receive immediate placeholder feedback.
  • Attachment cards: File-style UI includes filename, file size, icon treatment, and download affordance.
  • Article presentation: Article cards include title hierarchy, excerpt handling, read-more controls, and image placement.
  • Accessible labels: Navigation, icon buttons, search, filters, and form controls include ARIA-friendly labels.
  • Responsive behavior: Layout rules cover smaller screens, moving navigation and compressing controls as needed.

Technical Notes

A compact static build with no dependency installation required.

The prototype is implemented as a static front-end page. Styling is written directly in index.html using CSS custom properties, responsive media queries, and component-specific class names. The behavior layer is small, readable JavaScript at the bottom of the page.
